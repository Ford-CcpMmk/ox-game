# Requirement: เกม OX จากโจทย์

1. พัฒนาเกม OX (Tic-tac-toe) ในรูปแบบ Web Application
2. ผู้เล่นต้องเข้าสู่ระบบก่อนเริ่มเล่นเกม
3. ระบบเข้าสู่ระบบต้องใช้มาตรฐาน OAuth 2.0
4. กติกาเหมือน OX ทั่วไป โดยผู้เล่นแข่งกับบอท
5. มีระบบเก็บคะแนนของผู้เล่น
6. เมื่อผู้เล่นชนะบอท ได้รับ 1 คะแนน; เมื่อแพ้ เสีย 1 คะแนน
7. เมื่อผู้เล่นชนะติดต่อกันครบ 3 ครั้ง ได้รับคะแนนพิเศษอีก 1 คะแนน และเริ่มนับจำนวนครั้งที่ชนะติดต่อกันใหม่ ดังนั้นการชนะ 3 ครั้งติดกันได้รับรวม 4 คะแนน
8. มีเครื่องมือสำหรับตรวจสอบคะแนนของผู้เล่นทั้งหมด

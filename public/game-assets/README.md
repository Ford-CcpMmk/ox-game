# Game assets

Active files:
- `bot-friendly.png`: smiling beginner opponent.
- `bot-challenger.png`: sporty challenger with golden energy halo.
- `bot-boss.png`: crowned armored boss with coral/violet flame aura.
- `trophy.png`, `flame.png`: score and streak illustrations.
- `sounds/player-pop.mp3`, `sounds/bot-pop.mp3`: user-provided pop sounds.

Robot illustrations were produced with built-in imagegen using the original friendly
robot as reference. Shared prompt: preserve rounded robot identity, square arch
framing, pastel clay materials and transparent exterior; no text or watermark.
Challenger prompt: peach headband, raised fist, concentrated eyes, golden sparks
and halo. Boss prompt: violet/plum armor, gold crown, both fists ready, peach eyes,
large coral/violet flame aura and lightning.

Font Awesome supplies the gift, controls and difficulty icons.
